# オート競争グランプリ (Auto Race Grand Prix)

超本格オートレース育成シミュレーションゲーム

## 特徴

- **9画面構成**: タイトル → ホーム → バイク整備 / メンテナンス員選択 / 勲章・カップ / SS級選手一覧 / レース選択 / レース / 次の週
- **12種バイク部品**: エンジン、クランクシャフト、キャブレター、マフラー、フレーム、サスペンション、タイヤ、ブレーキパッド、スプロケット、クラッチ、燃料タンク、カウリング
- **競輪方式昇進**: 競争得点が初期値から上がるほど上がりにくくなる減衰システム
- **9人のSS級ライバル**: それぞれ固有の特殊能力を持つ
- **全賭式ベッティング**: 単勝・複勝・2連単・3連単
- **Canvas レース映像**: リアルタイム実況付き
- **4段階グレード**: 一般戦 → GII → GI → SG

## 遊び方

`index.html` をブラウザで開いてください。
